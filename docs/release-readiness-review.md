# Historical release-readiness review

This file records an earlier release review. It is not evidence that the current website revision is ready to publish.

The website has since changed its content source, visual design, topology explorer, asset workflow, and test coverage. Do not use old test counts or old source-file references from prior reviews.

Before publishing the current revision, run:

```sh
npm run validate:release
```

Then complete the required manual review of public wording, official logo files, external Form and briefing links, hosting settings, and accessibility on the deployed website.

For normal content and asset updates, use [`../HOW-TO-UPDATE-THE-WEBSITE.md`](../HOW-TO-UPDATE-THE-WEBSITE.md).
