# Draft and inspiration images

Use this folder for screenshots, ideas, and images that are not approved for the public website yet.

The website does not display or link to files in this folder. However, this folder is inside `public/`, so files can still be reached by someone who knows the exact address. Do not place passwords, private material, sensitive information, or anything that must remain private here.

When an image is approved for public use:

1. Move or copy the final file to `public/images/hero/`, `public/images/architecture/`, or `public/images/backgrounds/`.
2. Add the new path to `src/content/site-manifest.ts`.
3. Run `npm run build`.

Read [`../../../HOW-TO-UPDATE-THE-WEBSITE.md`](../../../HOW-TO-UPDATE-THE-WEBSITE.md) for the full update guide.
