# Bundled display font

`michroma-regular.woff2` is the unmodified Michroma Regular webfont from the [official Google Fonts Michroma repository](https://github.com/googlefonts/Michroma-font). It is used only for website display typography through `src/app/fonts.ts`.

The font is licensed under the SIL Open Font License 1.1. Its complete license is included in [`OFL.txt`](OFL.txt).

The supplied GEMSTONE SVG logo assets remain the approved source for the Tachyon-style official wordmark. Michroma is not used to recreate or alter those logo assets.

Content was rephrased for compliance with licensing restrictions.
