# Website display font

The website uses `michroma-regular.woff2` for display headings. It loads automatically when you run `npm run build`.

You do not need to change this folder for normal website wording, logo, image, or background updates. Use `src/content/site-manifest.ts` and the public asset folders instead.

The official GEMSTONE logo files keep their own approved wordmark. Do not replace the logo text with this font.

`OFL.txt` contains the license for Michroma.
